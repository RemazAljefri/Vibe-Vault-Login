# Login & Authentication Page | Cyber & Modern Interface

A sleek, responsive, and secure user login page built using modern **HTML5** and **CSS3**, designed with a modern dark theme and seamless form user experience (UX) standards.

## Features

* **Interactive Form Controls:** Clean input fields for credentials with clear focus states and validation visual feedback.
* **Centered UI Layout:** Utilizes CSS Flexbox/Grid to ensure the login container stays perfectly centered across all desktop and mobile viewports.
* **Responsive Visual Styling:** Custom styled action buttons, links for "Forgot Password?", and social login options with subtle hover effects.
* **Semantic Structure:** Structured using standard HTML5 forms and semantic input tags (`<form>`, `<input>`, `<label>`, `<button>`).
* **Custom Styling & Branding:** Dark mode background styling, crisp typography, and rounded form containers designed for optimal readability and accessibility.

## Tech Stack

* **HTML5** (Form Elements, Inputs, Placeholders)
* **CSS3** (Flexbox Alignment, Input Custom Styles, Hover States, Transitions)
